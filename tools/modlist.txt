# Skycraft mod list for Minecraft 1.20.1 / Forge 47.4.10
# Format: <source>:<slug> [| <fallback source>:<slug>]   # comment
# Sources: mr = Modrinth, cf = CurseForge. tools/build-pack.sh resolves each entry with packwiz
# (dependencies are added automatically) and fails if any entry can't be resolved.
# An entry whose pack/<mods|shaderpacks|resourcepacks>/<slug>.pw.toml already exists keeps that pinned version;
# to update a mod, edit or delete its .pw.toml.
# Skycraft prefers its own implementations over third-party feature mods: trees, followers, NPC dialogue, the map
# and physics are Skycraft Core's. Library and performance mods are fine.

# --- Performance (runs efficiently, even with huge view distances) ---
mr:embeddium                     # Sodium-based renderer for Forge (client)
mr:oculus                        # shader support (works with Distant Horizons) (client)
mr:distanthorizons               # Distant Horizons: LOD terrain to the horizon
mr:modernfix                     # faster launch, lower memory
mr:ferrite-core                  # memory usage
mr:saturn                        # more memory savings (complements FerriteCore/ModernFix)
mr:entityculling                 # skip rendering hidden entities (client)
mr:immediatelyfast               # faster immediate-mode rendering: HUD, text, maps (client)
mr:dynamic-fps                   # lower FPS when the window is in the background (client)
mr:canary                        # Lithium port: server tick optimisations
mr:krypton-fnp                   # Krypton (FNP/Reno): faster networking stack
mr:clumps                        # merges XP orbs: fewer entities
mr:structure-layout-optimizer    # faster jigsaw structure generation (towns, dungeons)
mr:memoryleakfix
mr:spark                         # profiler for diagnosing lag

# --- Core RPG behaviour (Skycraft Core is injected at build time from mod/build/libs; see docs/DEVELOPING.md) ---
mr:lootr                         # per-player loot chests: every player gets their own dungeon loot
mr:better-combat                 # directional combos and weapon swings
mr:corpse                        # player corpses keep your gear when you die
cf:dynamiclights-reforged | mr:dynamic-lights-reforged   # torches light up the world in your hand
mr:mouse-tweaks
mr:controllable | cf:controllable   # controller support (Steam Deck, gamepads)
mr:default-options               # ships default keybinds for new players
mr:essential                     # easy multiplayer hosting/invites with friends, skins & cosmetics
mr:itemphysic-lite | cf:item-physic-lite   # dropped items lie in the world with physics (Skyrim clutter)

# --- NPCs, factions (companions/followers are Skycraft's own) ---
mr:minecraft-comes-alive-reborn | cf:minecraft-comes-alive-reborn   # MCA Reborn: named, human-looking villagers (pinned to a stable release)

# --- Vampires, werewolves ---
mr:vampirism                     # vampirism: become a vampire (or hunter)
mr:werewolves | cf:werewolves-become-a-beast   # werewolf transformation

# --- Towns, cities, dungeons, roads and secrets ---
mr:terralith                     # Skyrim-like mountains and biomes
mr:tectonic                      # dramatic terrain
mr:ct-overhaul-village           # ChoiceTheorem's Overhauled Village: towns and cities
mr:towns-and-towers              # more settlements, castles and towers
mr:dungeons-and-taverns          # taverns (inns), dungeons
mr:when-dungeons-arise           # huge dungeons and fortresses
mr:moogs-voyager-structures      # lots of hidden structures
mr:explorify                     # small hidden ruins and secrets
mr:yungs-better-dungeons
mr:yungs-better-mineshafts
mr:yungs-better-strongholds
mr:yungs-better-desert-temples
mr:yungs-better-jungle-temples
mr:yungs-better-ocean-monuments
mr:yungs-better-witch-huts
mr:yungs-better-nether-fortresses   # Oblivion citadels
mr:yungs-bridges                    # bridges for the road network
mr:yungs-extras

# --- Survival: fishing, cooking, gear, backpacks, sleeping ---
cf:aquaculture | mr:aquaculture     # fishing overhaul (feeds the Fishing skill)
mr:comforts                         # sleeping bags and hammocks for camping

# --- Shaders (optional, client) ---
mr:complementary-reimagined         # shader pack with Distant Horizons support
