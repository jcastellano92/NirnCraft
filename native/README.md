# aether_core: Skycraft's native far-field engine

A C ABI library (`aether_core.dll`, `libaether_core.so`) that renders everything beyond the rasterised near field: distant terrain as
SVDAG voxel regions on a curved planet, then the cloud shell and far actors. One Slang kernel is compiled twice,
to SPIR-V for Vulkan and to C++ for a CPU reference, and the tests check that the two agree. Design and status:
[docs/AETHER.md](../docs/AETHER.md).

## Build

Toolchains live outside the repo in `F:\Projects\Personal\Skycraft\toolchains` (versions and SHA-256 in
`VERSIONS.txt`): Slang 2026.18.3, CMake 4.4.4, Vulkan SDK 1.4.357.0, Temurin JDK 25.0.4.1, Rust stable, and the
preinstalled MSVC 14.29 (VS 2019). `env.ps1` there puts them on PATH.

```powershell
.\native\build.ps1            # configure (first time), build Release, run aether_tests
.\native\build.ps1 -NoTest
```

Linux (Steam Deck, Bazzite, any distro): `native/build_linux.sh` builds `libaether_core.so` with GCC or Clang and
runs the same suites (`--software` on lavapipe/llvmpipe, `--glx`, `--hostcopy`, `--validate`; see its header and
docs/AETHER.md "Portability").

`native/data/tamriel_raster.bin` is a cache of the bundled map rasters for the offline harness, regenerated by
`py -3 -I native/tools/export_raster.py` (the build does this when it is missing).

## Offline renders

Run from the repo root:

```powershell
native\build\Release\aether_render.exe backend=vulkan out=native/out/view.png x=0 z=0 above=60 yaw=105 pitch=-3 sun=30,140
```

Arguments: `x z` (blocks), `above` (height over the ground) or `y`, `yaw` (0 = north, 90 = east), `pitch`, `fov`, `w h`,
`sun=elevation,azimuth`, `radius` (planet radius in blocks; 0 = flat), `far`, `bias` (LOD bias),
`flags=shadows,atmos,lod`, `frames` (best-of timing), `depthpng=1`. It prints one JSON line of stats.

These renders use **preview terrain** (raster macro shape and a seed-free stand-in for the detail), not the
game's generator. In game, Java pushes authoritative column tiles and chunk sections through the same ABI.

## Layout

| Path | What |
| --- | --- |
| `include/aether/aether.h` | the C ABI (Java binds it with `java.lang.foreign`) |
| `shaders/aether_far.slang` | far-field kernel: curved chords, LOD clipmap walk, SVDAG descent, shading |
| `shaders/aether_shared.slang` | GPU layouts, sky, aerial perspective, G-buffer packing |
| `src/svdag.*` | Aokana-style SVDAG builder: 4^3 leaf bitmaps, prefix counts, RLE materials |
| `src/world.*` | column tiles and sections in, clipmap of regions out, packing |
| `src/cpu_backend.cpp`, `src/vk_backend.cpp` | the two kernel backends |
| `src/preview_source.*` | offline-only terrain from the raster |
| `tools/aether_render.cpp` | offline renderer CLI |
| `tests/test_main.cpp` | SVDAG round trips, ABI, grazing rays, CPU/Vulkan parity |
