Behavior and compatibility gates

handlers now run through a supported DamageContainer ARMOR callback, preserving
stamina/XP and health scaling for accepted hits. Native armor durability has already
been charged using the original amount at that point; exact old wear timing is a
known limitation. No mixins or access transformers have been introduced.
Prewarm retains per-job UUID leases over shared native chunk tickets, so completion
of one overlapping journey cannot unload another's destination.

Required acceptance before calling the port complete
1. Full compile and build succeed on the exact target; tests retain real behavior.
2. All authored datapack/assets load through actual native codecs; generation
   scripts reproduce target resource paths and schemas.
3. A dedicated server boots and exercises world creation, dimensions, persistence,
   networking, inventory, combat, quests, NPCs, roads, dungeons and save/reload.
4. Isolated 26.3 client joins, normal multiplayer/LAN UI works, and all screens,
   controls, models, particles, clouds/fog/sky and lighting work in real scenes.
5. Before/after visual and motion checks cover shader-disabled and supported
   shader-enabled paths, plus performance and world readiness checks.
6. Customized shader/DH integration is either verified compatible or explicitly
   retained disabled with its exact remaining port work recorded.
7. Package the validated full instance into dist, verify zip contents/version
   metadata and include honest validation results. Do not ship the old core.
